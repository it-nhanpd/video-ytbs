# Prompt pack: s001 (Huey bay qua lúc hoàng hôn)

Bạn cần tạo **1 ảnh** bằng Nano Banana. Các lớp còn lại (trời, cây, sương, bụi, cánh quạt, grade) do code sinh.

## Asset 1: `huey_side` → thả vào `inbox/` với tên `huey_side` (đuôi `.jpg`, `.png` hoặc `.webp` đều được)

**Đính kèm ảnh tham chiếu:**
1. Ảnh Huey UH-1D nhìn ngang (tham chiếu tỉ lệ)
2. (tùy chọn) frame Huey hoàng hôn của video gốc, chỉ để bắt màu/cách tô

**Prompt (dán nguyên văn):**
```
Bell UH-1D Iroquois "Huey" military helicopter, strict side profile view facing LEFT, olive drab paint,
open sliding cargo door showing three soldiers in M1 helmets standing inside, pilot visible in cockpit,
"UNITED STATES ARMY" in small black capital letters on the tail boom, skids, red anti-collision light on tail fin,
NO main rotor blades and NO tail rotor blades (mast stub and hub only, blades are added later in animation),
full helicopter fits inside the frame, wide landscape composition,
solid flat uniform neutral gray background (#808080), perfectly even with no gradient, no vignette, no texture, no noise,
helicopter centered with at least 12% empty margin on every side and the bottom-right corner completely empty,
no ground, no shadow, no reflection, no other objects, single subject only,
no part of the helicopter uses the same neutral gray as the background: the cabin interior behind the soldiers and the
view through the open door must be deep shadow (dark olive/black), not gray,
2D animated documentary style, clean dark ink outlines of even thickness, flat cel shading with two tones
(light and shadow), subtle warm rim light, muted earthy palette, hand-drawn animation look,
no photorealism, no 3D render
```

**Yêu cầu đầu ra:**
- Tên file `huey_side` + đuôi bất kỳ trong jpg/png/webp (không cần đổi đuôi, `ingest` tự ép về PNG RGBA)
- Tỉ lệ khung 16:9 hoặc 5:2 đều được (có bước crop)
- Nền xám phẳng đồng nhất, trực thăng nhìn ngang, đầu hướng trái, **không có cánh quạt**
- Góc dưới phải trống (Nano Banana gắn watermark ở đó, `ingest` sẽ crop bỏ)

**Checklist QA trước khi thả vào inbox:**
- [ ] Đúng UH-1D (thân rộng, mũi tròn, cửa trượt), không phải Cobra/Chinook
- [ ] Không có cánh quạt
- [ ] Nền phẳng đồng nhất, không bóng đổ dưới thân
- [ ] Trực thăng cách mép khung ≥12%, góc dưới phải trống
- [ ] Nội thất khoang tối, không có mảng xám giống màu nền
- [ ] 3 lính trong cửa, mũ M1
- [ ] Chữ không sai chính tả (nếu sai, chấp nhận hoặc xóa chữ sau)

## Sau khi tạo xong
1. Thả file vào `inbox/`.
2. **Hiệu chỉnh `manifest.json`** (`crop`, `anchors`, `fit`) theo ảnh thật: nhờ Claude dùng skill `prompt-pack`, hoặc tự đo (tọa độ theo pixel ảnh gốc).
3. Chạy:
```
npm run ingest -- test-huey      # ép PNG, crop, tách nền, trim, đưa về 5:2, cập nhật scenes.json + rotors
npm run validate
npm run render -- test-huey-s001 content/projects/2026-test-huey/renders/s001_final.mp4
```
4. Xem lại 1 still để tìm viền bẩn/lỗ/cánh quạt lệch: `npm run still -- test-huey-s001 content/projects/2026-test-huey/renders/check.png --frame=191`
